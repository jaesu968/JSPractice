# JSPractice

A small JavaScript shop project built in three stages. Each stage adds more logic
to `My First Project (JavaScript)/task/task.js`.

## Stage 1 — Print the prices

Defined a `products` object mapping each product to its price and looped over its
entries to print every product with its price under a `Prices:` heading.

## Stage 2 — Measure the total income of your shop

Added a `sales` object holding the amount earned per product, printed each product
with its earnings under an `Earned amount:` heading, then summed all the sales to
report the shop's total `Income:`.

## Stage 3 — Calculate net income

Prompted the user for staff expenses and other expenses using `sync-input`,
subtracted both from the total income, and printed the resulting `Net income:`.
